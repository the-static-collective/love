# Fifty First Dates 001

LOVE treats every encounter as a new occurrence.

History informs. History does not replace the present.

## Re-entry

```text
DATE 003
rainy diner
talked until closing

DATE 031
same diner
same booth
same two people
```

These are not the same event.

```text
occurrence_003 != occurrence_031
```

## reenter@1

A prior door can be intentionally reopened.

The comparison asks:
- what persisted?
- what changed?
- what disappeared?
- what newly appeared?
- what became reachable?
- what became unreachable?

## KEEP / RELEASE / REDISCOVER

After an encounter each person may choose which shared memories are actively foregrounded for the next crossing.

This is not literal amnesia. It is a composition rule preventing the application from turning history into destiny.

## Relic return

A later encounter may surface a prior shared artifact:

```text
RELIC FOUND:
On occurrence 003, both participants independently photographed the same yellow door.
```

The relic is evidence of a past occurrence, not proof of a trait.
