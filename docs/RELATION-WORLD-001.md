# Relation World 001

## Purpose

The relation world is a projection of the save file.

It answers:

> What exists between these people now, and what can be reached from it?

It does not answer:

> How good is this relationship?

## Regions

~~~text
MAILBOX
transport / pending response

THE ROOM
jointly admitted history

THE HORIZON
reachable but uncrossed possibility
~~~

These regions are state categories, not emotional judgments.

## Example path

~~~text
mail-001
  --carried proposal-->
mail-001-proposal@r1
  --became-->
door-mail-001
  --crossed as-->
occurrence-004
  --left relic-->
two annotated postcards
  --held by-->
The Postcard Table
  --reachable-->
choose one postcard destination
~~~

This path can be reconstructed from receipts.

## Dogram edges

A Dogram probe becomes an edge between historical occurrences.

~~~text
occurrence-001 --delta@1--> occurrence-002
occurrence-001 --reenter@1--> occurrence-003
occurrence-003 --delta@1--> occurrence-004
~~~

The edge describes a comparison operation, not a score.

## World law

~~~text
THE MAP IS A VIEW OF THE SAVE FILE.
THE MAP IS NOT AN AUTHORITY OVER THE SAVE FILE.
~~~

Deleting or rearranging a visual node must never silently rewrite historical receipts.
