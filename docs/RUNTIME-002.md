# LOVE Runtime 002 — The First Real Delta

Runtime 001 could establish a baseline.

Runtime 002 can compare two historical occurrences without converting the people into scores.

## Comparative sequence

```text
Occurrence 001
    |
baseline@1
    |
relation inventory
    |
choose Door 002
    |
declare one perturbation
    |
mutual acceptance
    |
Occurrence 002
    |
delta@1
    |
categorical residual
    |
relation inventory update
```

## Why the perturbation is declared before the crossing

If the changed condition is named only after the result is known, the system can tell itself almost any story.

Runtime 002 therefore stores the Door 002 perturbation before occurrence 002 is receipted.

Examples:

- remove shared acquisition task
- discovery task -> coordination task
- in-person crossing -> asynchronous correspondence

The declaration is not a claim that every resulting difference was caused by that perturbation. It identifies the comparison being attempted.

## What delta@1 may compare automatically

Runtime 002 compares only fields with a direct receipt-level relation:

- planned / actual duration
- repeated artifact strings
- newly recorded artifact strings
- repeated question strings
- newly recorded question strings
- repeated observation strings
- newly recorded observation strings
- explicitly resolved prior items

This is deliberately conservative.

## The omission law

Suppose occurrence 001 records:

```text
comfortable silence
```

and occurrence 002 does not mention it.

Runtime 002 does **not** emit:

```text
disappeared:
  - comfortable silence
```

That conclusion is not licensed.

It emits no disappearance claim.

Likewise, an unresolved question absent from occurrence 002 becomes:

```text
status unknown; prior unresolved item was not repeated
```

unless the participants explicitly receipt it as resolved.

## The relation can change without scoring the humans

The delta can update:

- shared relic inventory
- unresolved questions
- reachable future doors
- occurrence history

It cannot update:

- compatibility percentage
- desirability
- relationship grade
- participant rank

The result is a growing historical object, not a verdict.
