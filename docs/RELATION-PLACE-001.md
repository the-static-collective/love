# Relation Place 001

A relation place is an explicitly named composition of shared history.

## Minimal form

~~~yaml
place_id: place-001
name: The Postcard Table

source_occurrence_ids:
  - occurrence-004

relics:
  - two annotated postcards

unresolved:
  - whether either proposed place should become a future crossing

reachable_from_here:
  - choose one postcard destination
  - reenter a prior door
~~~

## Formation

A place must have:

- a human-authored name
- at least one selected historical source

LOVE may present candidate material.

LOVE does not assign the meaning.

## Snapshot semantics

reachable_from_here is captured when the place forms.

It is therefore historical context, not a permanently live recommendation set.

Later runtime versions may distinguish:

~~~text
reachable_when_formed
reachable_now
~~~

without overwriting the original snapshot.

## Core law

~~~text
THE CROSSING BECOMES A PLACE
~~~

not because every crossing automatically is one, but because relation history can become a stable address when participants explicitly compose it that way.
