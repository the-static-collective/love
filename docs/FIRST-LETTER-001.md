# First Letter 001

The first interface is not a face grid.

It is mail.

## Input

Each participant privately answers a small seed set. Example dimensions:

1. Something you can teach with your hands.
2. A place that changes how you think.
3. A harmless thing you are irrationally delighted by.
4. Something you prefer to do slowly.
5. A boundary that makes meeting easier.
6. A question you are currently living.
7. One offered thread the other person may pull.

The complete answers are not automatically revealed.

## Composition

The system may use private seeds to compose:
- a letter prompt
- one optional artifact prompt
- one possible first quest

It must not quote hidden material into the letter unless the participant explicitly chooses to reveal it.

## Gate

```text
A writes -> B receives
B writes -> A receives
A opens? yes/no
B opens? yes/no

yes + yes -> Door 001 may be composed
anything else -> no crossing
```

No penalty for decline.

## Product copy target

```text
You have received a letter.
There may be a person on the other side.
```
