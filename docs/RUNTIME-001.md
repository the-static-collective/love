# LOVE Runtime 001

Runtime 001 makes the protocol walk.

## Scope

The runtime is intentionally local and single-browser.

It demonstrates the constitutional path before network identity, matchmaking, moderation, or logistics complicate the model.

## State boundary

The browser holds:

```text
participants
letters
mutual-open gate
door
door acceptance
encounter
dogram receipt
relation inventory
```

Private seed inputs remain local runtime state and are not automatically copied into the other participant's visible letter.

## First Dogram rule

The first occurrence runs:

```text
baseline@1
```

not:

```text
delta@1
```

because there is no prior comparable occurrence.

Unknown remains unknown.

## Persistence

Runtime state is persisted locally so the relation can survive page reloads without a remote account.

The export function produces a portable JSON relation snapshot.
